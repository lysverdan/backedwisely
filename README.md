Placeholder landing page for Backed Wisely Inc. — the parent company behind Good Car Bad Car and the consumer intelligence verticals to follow.

## Files
- `index.html` — the page
- `logo.png` — Backed Wisely logo

## Deploying to GitHub Pages
1. Push this repo to GitHub.
2. Go to **Settings → Pages**.
3. Under **Source**, select branch `main` and folder `/ (root)`.
4. Save. The site will be live at `https://<your-username>.github.io/<repo-name>/` within a minute or two.

## Custom domain (when ready)
- Add a `CNAME` file containing your domain (e.g. `backedwisely.com`).
- Point your domain's DNS to GitHub Pages per their docs.
